# Changelog

## 0.1.1

First GitHub release of the native macOS app.

- Record a display, window, camera, or screen with camera at native resolution.
- Save local MP4 videos in Movies/Relay, with microphone and system audio options.
- Pause, resume, mute, and finish from the menu bar or floating camera.
- Move the circular camera above other apps; reveal controls and a resize grip on hover.
- Open the studio from a draggable quick launcher.
- Browse, play, rename, reveal, or move recordings to Trash in the native library.
- Use AppKit AVPlayerView for playback, replacing the SwiftUI player implicated in the reported post-recording crash.

The downloadable build is for Apple Silicon Macs running macOS 15 or later. It is locally signed and is not Developer ID signed or notarized.
